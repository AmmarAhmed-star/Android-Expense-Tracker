### 🎨 Attractive CSS — What Makes This Page Beautiful?

This page uses modern attractive CSS, not boring plain CSS:

- `backdrop-filter: blur(12px)` — Glass navbar
- `radial-gradient` — Hero glow effect behind title
- `linear-gradient(90deg,#EA580C,#F59E0B)` — Orange to Yellow gradient for buttons & header
- `border-radius: 22px` — Extra rounded cards (modern)
- `box-shadow: 0 10px 30px rgba(234,88,12,.08)` — Soft orange shadow
- `transform: translateY(-2px)` on hover — Lift effect for cards & chips
- Gradient active chips with shadow
- Phone mockup with 36px radius + deep shadow
- Attractive budget bar with gradient
