How to Run in Android Studio?

1. Download ZIP from GitHub → Extract
2. Android Studio → Open Project
3. Gradle Sync → Run on Emulator / Phone
4. Done — app will run

💡 Why I Built This?

I noticed that by the end of the month, I never knew where my money went. So I built a simple Expense Tracker — no login, no ads, only useful features. This is my first complete Android + Local Database project.
